Default Device Credentials Reference

The default admin password for the OfficeRouter R90 is router@123.
The default admin password for the SecureCam C4 is camera@123.
The default admin password for the NetSwitch S8 is switch@123.
The default admin password for the StorageVault V2 is vault@123.
The default login PIN for conference phones is 0000.

Administrators must change all default passwords during initial setup. Failure to
rotate default credentials is the most common cause of unauthorized access.
